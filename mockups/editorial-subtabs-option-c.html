What this change involves & what it costs
Bigger than Option A, but everything is plumbing in updateOePageHead + redundant page-title removal in three files.

Build steps

  • Extend updateOePageHead: add Capacity and Analytics branches alongside the existing Portfolio one. Each builds an oe-page-head-left (eyebrow + title) plus an oe-pagetabs strip mirroring the current sub-bar entries (Resources/Forecast/Insights for Capacity; Team Load/Effort Shape for Analytics). Tabs read counts where applicable.
  • Extend the sub-bar CSS hide: the rule that currently hides the sub-bar only on Portfolio under OE — body[data-theme="oe"][data-active-group="portfolio"] #sub-bar { display: none } — extends to [data-active-group="capacity"] and [data-active-group="analytics"].
  • Remove redundant in-page section titles from Resources, Forecast, Insights, Team Load, and Effort Shape — each currently renders its own eyebrow + "Capacity" / "Analytics" / etc. h1. The editorial band above replaces them.
  • Each tab's content-level header stays when it's tab-specific (e.g. Resources still shows the "Team capacity · Feb 2 – Jun 21" date eyebrow because that's data-driven and tab-specific, not the section title).

Estimate: ~80 lines of new/changed code across render.js, theme-oe.css, and 5 tab renderers. One commit.

Trade-offs vs Option A

  • Pro · brand consistency. Every primary group reads with the same Laura editorial framing — eyebrow, large serif display title, underline tabs. It looks like one designed product instead of two visual idioms.
  • Pro · keeps the section-title affordance. Leadership / screenshots get "Capacity" rendered as a clear h1 the same way they get "Portfolio" — useful when paging through PDFs or copying surfaces into reports.
  • Con · more vertical real estate. The editorial band is ~80px taller than the sub-bar. After the spacing-tighten commit we just shipped, this re-adds ~60px of top space on Capacity / Analytics. Worth noting because that's the opposite of yesterday's "shrink the empty space" request.
  • Con · bigger change. Option A is a 3-line CSS toggle. Option C touches ~5 tab renderers to remove the in-page section titles that would duplicate the editorial band.
  • Con · the count chips disappear in places. Resources / Forecast / Insights don't have counts today; Team Load / Effort Shape don't either. So the underline tabs read without chips — which is fine and matches the original Laura pattern, just noting it.

If you want to weigh Option A vs Option C

  • Option A — Portfolio drops to sub-bar pills. Faster to ship, tighter spacing, every group reads like a utility. Loses Laura's intent on Portfolio.
  • Option C — Capacity + Analytics adopt editorial headers. Honors Laura's design system across the app, every group reads with the same anatomy. Adds back ~60px of vertical space on Capacity / Analytics.
