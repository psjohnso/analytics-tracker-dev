Organization editor — inline editing

Live mockup. Everything is editable in place — no popup dialogs. This is the alternative to the prompt() version currently wired into the app.

Try it: click any team/department name (or its ✏️) to rename in place · click ＋ add unit and type — press Enter to add and keep going, the input stays focused for the next one · Esc cancels any edit · ↑ ↓ reorder · 🗑 removes. Save/Discard light up once something changes.
