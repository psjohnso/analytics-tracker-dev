Planned vs Actual — by Employee × Project Category

Three layout options for the same data. Planned = the original weekly allocation estimate captured by the snapshot pipeline when each week was current. Actual = that same week's allocation value after it was updated to reflect what really happened. Variance = (actual − planned) ÷ planned. Numbers below are illustrative sample data — identical across all three options so you're comparing layout, not content.

Where it slots: A new section on the Capacity → Insights tab, below Duration Calibration. The Team / Unit / Member filter row scopes the whole section.
Visibility: per-person rows show by name only to team leads and to each person's own row — same pattern as Duration Calibration. Aggregates (category subtotals, KPIs) are visible to everyone.
Data dependency: "Actual via snapshots" needs enough accrued weekly snapshots to compare against. Until several weeks accumulate the variance will be thin or empty for recent weeks — the section will show a "building history" note rather than misleading numbers.

Category-first

Group by project category (with a category subtotal row), employees nested underneath. Best for "which categories are we systematically mis-estimating, and who drives it."

Option 2

Employee-first

Group by employee (with a per-person subtotal row), categories nested underneath. Best for a 1:1 / capacity conversation: "how did this person's plan vs reality break down across their work."

Option 3

Matrix heatmap

Employees as rows, categories as columns; each cell is the variance %, color-coded. Most compact and scannable — patterns jump out, but it hides the raw planned/actual hours (shown on hover in the real thing).
