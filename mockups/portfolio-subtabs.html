What this change involves

  • One CSS rule removed (body[data-theme="oe"][data-active-group="portfolio"] #sub-bar { display: none }) so the existing sub-bar shows on Portfolio under OE.
  • The OE editorial title row (#oe-page-head) is hidden for Portfolio. Currently it renders "All teams · City of Tucson / Portfolio" with the tabs on the right. That whole block goes away on the Portfolio group.
  • The .oe-pagetabs / .oe-pagetab CSS stays in place — it's still used by any other surface that wants underline-style tabs (none today, but the system stays available).
  • Sub-bar styling is already responsive — same behavior you see on Capacity / Analytics.
  • Net result: Portfolio, Capacity, and Analytics all use the identical sub-bar treatment. One mental model instead of two.
Trade-off worth naming
The editorial "All teams · City of Tucson / Portfolio" header is the visible cost of the change. It was Laura's design intent — Portfolio gets that "section title" treatment the same way the Initiatives detail page or My Work hero do. If you like that treatment, there's a third option: keep both.

Three paths if you want to weigh them

  • A. Just the swap (proposed above): Drop the editorial header on Portfolio. Use the sub-bar. Cleanest, most consistent with Capacity / Analytics. The "Portfolio" title becomes the primary-tab pill instead.
  • B. Sub-bar + thin editorial title: Keep "All teams · City of Tucson / Portfolio" as a thin band ABOVE the sub-bar (no tabs in it — just the title). Sub-bar holds the tabs underneath. More vertical real estate, but preserves Laura's editorial framing.
  • C. Don't change Portfolio — bring Capacity / Analytics up to Laura's style instead: Move Resources / Forecast / Insights / Team Load / Effort Shape into their own editorial title rows with right-aligned underline tabs, matching today's Portfolio. Bigger change, but consistent in the opposite direction.

A is what the mockup above shows. B is a small CSS tweak away from A (add a band). C is more work and reverses the spirit of your "tighten the top spacing" request from the previous commit.
