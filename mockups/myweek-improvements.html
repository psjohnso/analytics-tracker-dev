Summary of code changes (once you approve the design)

  • Logic fix — in my-work.js around line 1137, change isMissingTasks from pendingTasks.length === 0 to pendingTasks.length === 0 && doneTasks.length === 0. When the user has finished everything for the week, show the completed list (with a green "All tasks completed this week" header) instead of the orange warning.
  • Visual distinction — wrap each project's allocation row + tasks in a new .mw-project-group container with a 1px border, 8px radius, ~14px gap below, and a subtle shadow. Allocation row's existing white background becomes #FAFBFD inside the group so it reads as the group's header. The orange missing-tasks card style still wins when applicable.
